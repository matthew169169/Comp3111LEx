# Lab1 – Comp3111LEx

This folder contains the Lab1 Java sources for the Comp3111LEx Maven project.

## Files

- `mainApp1.java` – main application that calls the library
- `Screenshot 2026-09-17 at 22.48.50.png` – IntelliJ screenshot (Project tree, decompiled class editor, Git Log)
